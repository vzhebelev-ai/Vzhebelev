# Дневник тренировок

Веб-приложение для домашней программы A/B/C (3 раза в неделю): отмечать подходы, смотреть историю и отчёт, читать технику упражнений.

## Возможности

- **Тренировка** — выбор дня A/B/C (приложение подсказывает следующий), чек-лист разминки плеча, подходы с повторами и весом, отметка ✓, таймер отдыха, «прошлый раз», цель повторов на текущую неделю 6-недельной прогрессии. Отметки самочувствия (плечо, голеностоп) и заметка.
- **Питание** — цель 63 → 68 кг к 31 декабря: журнал веса с графиком и планом набора, рацион на ~2900 ккал (38 лет, сидячая работа + прогулки + 3 тренировки) из 5 приёмов пищи с отметкой съеденного, калории и белок за день, замены продуктов, правила корректировки. Связано с тренировками: подсказки по времени еды в тренировочные дни, сводка питания на вкладке «Тренировка», вес и питание в отчёте.
- **История** — все завершённые тренировки с подходами, тоннажем и отметками самочувствия.
- **Отчёт** — тренировки, подходы, повторы и тоннаж за 4 недели / 6 недель / всё время; график по неделям с регулярностью; график прогресса по упражнению; личные рекорды.
- **План** — полный план, стартовые веса, прогрессия, этап после 10 ноября. У каждого упражнения есть подсказки по технике и ссылка на видео на YouTube.

Данные хранятся в браузере (localStorage). На вкладке «План» можно скачать резервную копию в JSON и загрузить её на другом устройстве.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Чтобы пользоваться с телефона, включите GitHub Pages: Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`. Затем на телефоне «Добавить на главный экран».

## Файлы

- `nutrition.js` — рацион, калории, цель по весу, замены и правила.
- `plan.js` — упражнения, подходы, веса, техника и ссылки на видео. Чтобы изменить план, правьте этот файл.
- `app.js` — логика приложения.
- `styles.css` — оформление (светлая и тёмная тема).
